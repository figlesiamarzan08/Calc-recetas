# Calc-recetas# Calc Recetas

Una calculadora sencilla para recetas de pan y repostería.  
Introduce el peso total y los porcentajes de cada ingrediente, y la app calculará automáticamente las cantidades exactas.

## Cómo usar
1. Abre `index.html` en tu navegador.
2. Escribe el peso total de la receta.
3. Ajusta los porcentajes de los ingredientes.
4. Haz clic en **Calcular** y verás los resultados.
